Regex :-
Regex (Regular Expression) is a sequence of characters used to search, match, and validate patterns in a string.

In React, Regex is commonly used to validate user input, such as email addresses, mobile numbers, passwords, and usernames.

Test method:-
The test() method checks whether a string matches a regular expression and returns true or false.

regex.test(email)

What is the difference between test() and match():-

- test() returns true or false.
- match() returns matching information or null.
